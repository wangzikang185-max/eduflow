# 学序 EduFlow · V2 需求与验收

版本：2.0.0。本文描述当前正式入口 `frontend/src/v2/WorkspaceApp.tsx` 对应的需求与验收规则。

相关文档：[架构与扩展](项目介绍.md) · [接口文档](接口文档.md) · [验证记录](验收记录.md)。

## 1. 目标与交付范围

实现从建班、建档、开课、授权、选课，到考试、成绩、点名和学业分析的真实教务流程。所有 V2 页面访问 Java HTTP 接口和 MySQL；不以 localStorage 或 mock 代替业务持久化。

## 2. 角色和数据范围

公共界面 REQ-UI-01–05：保留页面导航与刷新定位、窄屏菜单、全局学生搜索（管理员/教师，Ctrl/Cmd+K 聚焦并跳转学生页）、加载/错误/空状态、成绩/考勤草稿保护及文档帮助。本机显示名称按账户 ID 保存在当前浏览器，不改变数据库角色或数据范围；个人设置同时提供真实改密入口。固定演示通知不作为真实消息系统交付。

| 能力 | ADMIN | TEACHER | STUDENT |
| --- | --- | --- | --- |
| 学生列表和详情 | 全部 | 仅本人授权课程的选课学生；隐藏手机号和邮箱 | 禁止；通过门户查看本人 |
| 学生及班级维护、CSV 导入、删除 | 允许 | 禁止 | 禁止 |
| 课程目录 | 全部 | 仅授权课程 | 可查看选课目录及容量，不含其他学生名单 |
| 课程维护及管理员选课 | 允许 | 禁止 | 禁止 |
| 考试、成绩、点名 | 全部 | 仅授权课程 | 禁止操作；门户只读本人 |
| 学生自助选退课 | 通过管理入口 | 禁止 | 仅本人 |
| 综合统计 | 全部 | 仅授权课程和对应学生 | /reports 只返回本人记录；页面使用门户 |
| 账户开通、启停、教师课程授权及审计 | 允许 | 禁止 | 禁止 |
| 改自己的密码和退出 | 允许 | 允许 | 允许 |

后端从已验签的 JWT subject 查询真实账户；请求体中的角色、operatorId 或 enrolled 不能扩大权限。教师授权每次请求检查数据库，撤销后立即生效。学生身份由账户的唯一 student_id 绑定，不能在门户提交他人 ID。

首次空账户库必须设置 ADMIN_PASSWORD，以 BCrypt 初始化 admin；没有公开默认密码。JWT_SECRET 至少 32 字节；密钥/数据库密码从环境变量读取。JWT 有效期 1800 秒，验证签名、issuer、时间、enabled 与 token_version。退出、改密和账户启停增加 token_version，因此所有旧登录失效。客户端令牌仅保存在 sessionStorage；不提供刷新令牌。

## 3. 学生档案和班级

- 学号去首尾空白，4–20 位字母数字短横线，数据库唯一索引以 utf8mb4_0900_ai_ci 比较；姓名去空白后 1–30 字。
- 性别：男/女/未说明；学籍：在读/休学/已毕业。日期必须为真实 YYYY-MM-DD，年份 1000–9999。
- 班级必须存在于班级表，专业只由该班级的 major 推导，不信任客户端 major。
- 手机可空，非空为 `1[3-9]` 开头的 11 位数字；邮箱可空，非空校验格式，最多 254 字。
- 关键词匹配姓名、学号、手机号，可组合班级与学籍。page≥1，pageSize 1–200；MySQL COUNT 与 LIMIT/OFFSET，按创建时间和 ID 倒序稳定分页。
- 编辑必须传 version，更新成功加一；旧版本 409。body.id 不改变路径目标。
- 班级名称和专业均 1–40 字；名称唯一。修改名称/专业时事务同步学生资料并增加学生版本；已有学生的班级不能删除。
- 新增学生不自动选课；选课关系有单独入口。

### 3.1 删除

仅管理员可删除 1–500 个不重复学生 ID，存在任一无效目标时整批回滚。正常删除同时清理该学生的选课、全部考试成绩、考勤明细，禁用并解绑学生账户、撤销其旧令牌；保留课程、考试及点名表本身。页面确认框必须提示关联数据和不可恢复性。无外键场景由 Service 保证清理；不删除其他学生记录。

### 3.2 CSV

表头固定：`学号,姓名,性别,班级,手机号,邮箱,状态,入学日期`。UTF-8 可带 BOM，文件不超过 2 MiB，1–500 条数据记录；支持带引号的逗号、换行和双引号。JSON 方式上传 `{csv:"..."}`，JSON 请求体额外限制 16 MiB，避免转义后合法 CSV 被 2 MiB HTTP 限制截断。

Apache Commons CSV 解析后，逐条校验并报告 CSV 记录号（含表头；带引号跨行记录不等于物理文本行号）。文件内及数据库重复、非法字段/日期、错误表头/列数、坏引号均整批拒绝，异常后没有部分学生落库。文件和数据库的比较规则不同造成的唯一键冲突仍会在事务内整批回滚，返回 409。导出可选当前筛选结果或已选学生，正确转义并阻断电子表格公式；只导出有权限的数据。

## 4. 课程和选课

课程代码 2–20 位字母数字短横线，唯一；名称 1–40 字，教师显示名 1–50 字、教室 1–100 字；简介 0–200 字。类别为专业必修/公共基础/专业选修。学分 0.5–10、步长 0.5；课时整数 1–300；容量整数 1–10000；星期整数 1–7；时间 HH:mm–HH:mm，同一天内结束晚于开始。颜色为 orange/blue/purple/teal/pink/amber。

teacher 是显示名称；教师权限依赖独立 user_course 授权，不能靠同名判断。enrolled 从 enrollment 计数，前端不能覆盖。创建课程自动建立“课程考核”默认考试，初始权重 100；修改课程必须带 version，容量不得低于当前选课人数。

管理员一次为 1–500 个不同的在读学生选课；学生只可为本人选课。课程行 FOR UPDATE 加锁，使用 READ COMMITTED 后查询最新人数，避免旧快照导致超额。任一学生不存在、重复选课、学籍不符或容量不足则整批失败。选课同时为该课程的全部考试初始化 null 成绩；新增考试也为所有已选学生初始化成绩。

退课仅限尚无已录入成绩且没有历史考勤的关系；允许清理其空成绩后退课。课程存在选课或成绩/点名历史时拒绝删除；可删除空课程及其空考试和教师授权。删除课程和考试需要 version。

## 5. 考试和成绩

每课程可有多次考试。名称 1–40 字、同课程内唯一；真实日期；weight 为 0.01–100 的相对权重、最多两位小数。权重不要求加起来为 100，汇总时归一化。管理员和该课程教师可管理考试，已有非 null 成绩的考试不能删除。

每名选课学生每次考试恰有一条成绩，唯一键为 `(exam_id,student_id)`。score 为 null 或 0–100、最多两位小数；null 不等于 0。修改按学生提交 `{studentId,score,version}`，禁止重复和课程外学生；缺失 score 无效，清空使用 null。

一批最多 10000 个修改项，在同一事务中条件更新；任意输入非法、版本冲突或 SQL 失败均回滚整批。成绩页先选真实课程再加载考试，不请求固定演示 ID。班级/姓名/学号筛选和分页影响表格与导出；统计针对当前考试的全部已保存成绩，不受表格筛选影响。显示平均分、及格率、优秀人数和四级分布；未录入不进入分母。

编辑草稿在保存失败后保留；切换课程/考试、导航或关闭页面需确认。未保存修改时禁用导出和考试管理，避免导出范围与状态混淆。

## 6. 考勤

每课程每日一张点名表，唯一键 `(course_id,attendance_date)`；状态 present/late/absent/leave。首次 GET 只为当前在读且已选课学生组装预填出勤记录，savedAt=null、version=-1，不创建数据库历史。

首次保存 version=-1，之后更新带服务器 version。请求提交完整名单，不能只交筛选结果；“当前筛选全部出勤”只修改界面筛选范围，最终仍提交全部名单。重复、漏交、课程外学生和过期版本均拒绝。表头与全部明细在同一事务保存，重复保存更新原表。已保存表从历史明细读取名单，即使学生后来休学/毕业也保留；学生被明确关联删除属于第 3.1 节的例外。

没有保存过不能导出或计入统计；有草稿禁止导出，离开需确认，保存失败保留草稿。

## 7. 工作台和综合报表

| 指标 | 定义 |
| --- | --- |
| 学生/在读数 | 管理员统计全部档案；教师只统计授权课程的选课学生并去重 |
| 课程人数 | 对应 enrollment 行数 |
| 当前考试均分/及格率 | 已录入分数之和 / 非 null 数；分数≥60 的非 null 数 / 非 null 数 |
| 成绩分布 | 优秀≥90，良好[80,90)，合格[60,80)，待提升[0,60)；空值不计 |
| 学生课程加权均分 | Σ(已录入分数×考试权重) / Σ(已录入权重)；未完成项不按 0，另显示完成度 |
| 工作台均分 | 已有成绩的学生课程加权均分再取算术平均，页面标注这一口径 |
| 出勤率 | (present+late) / 全部已保存考勤明细；leave 也进入分母 |
| 建档趋势 | 当前保留的档案按 create_time 月份聚合；属于建档时间分布，不是不可变历史快照 |

零数据返回数量 0，报表无成绩/考勤值为 null，页面显示“— / 未录入 / 未点名”，不伪造 96.8% 或上期比较。教师不显示全校建档趋势。

报表按课程、班级和起止日期筛选。日期区间分别约束考试 exam_date 和考勤 attendance_date，边界包含当天；选课存在但区间内无考试仍可显示 0/0 和无成绩。记录以“学生×课程”为单位，分页展示并支持 CSV 导出。预警筛选：已录入均分<60 或已有点名的出勤率<80%；没有数据的学生不自动判低分，完成度单列。

## 8. 数据结构、事务与审计

11 张业务表：student、class、course、enrollment、exam、grade、attendance_sheet、attendance_record、user、user_course、operation_log；另有 flyway_schema_history。沿用 eduflow_ 前缀，均不设外键。

V1 迁移创建原 8 表；V2 新增班级、选课、考试及版本字段。已有学生 ID/资料保留；已有课程成绩迁到默认考试；只把已存在的成绩/点名关联转成选课，不为全部学生隐式选课。Flyway 为旧非空库登记 baseline 0 后顺序升级，仅执行一次。升级前备份，禁止在已有 V2 库反复手动执行 ALTER。

Service 使用事务处理班级同步、选课/退课、CSV、成绩、删除和点名。课程行锁先于学生行锁；version 条件更新负责拒绝陈旧编辑，事务隔离使用 READ COMMITTED。唯一索引负责最终冲突兜底，CHECK 约束负责合法数值和枚举。

审计记录写操作的 HTTP 结果、真实 operator_id、动作、目标和时间。学生/课程/班级/账户的单目标更新、删除记录存在性及版本前后摘要，不复制姓名、手机号、密码或 Token；批量写入记录动作及结果摘要，不宣称拥有逐单元格的成绩变更历史。失败审计通过 REQUIRES_NEW 在业务回滚后保存。Spring Security 过滤链拒绝、413 等未进入控制器的请求不属于业务审计表覆盖范围。

## 9. 非功能要求与边界

- 默认回环地址运行；开发 Vite 代理 /api，生产产物提供本地同源代理和 Nginx/Compose 配置。公开部署需要另配 HTTPS、真实域名、备份和运行监控。
- Java 21、Spring Boot 4.0.8、MyBatis 4.0.1、MySQL 8.0.34；React 19、TypeScript 5.8、Vite 6.4。依赖由 Boot BOM 对齐，日志全局 INFO。
- 参数绑定 SQL，无客户端 SQL 拼接；统一 `{code,msg,data}`，区分 400/401/403/404/409/413/429/500。
- 保存中防重复操作，错误提示可重试，窄屏导航和表格滚动可用；sessionStorage 令牌不代表具备 HttpOnly Cookie 的 XSS 隔离能力。
- 学生查询在数据库分页；课程、选课名单、考试、成绩、考勤和综合报表面向小规模工作区，整组读取后前端分页。未做压测，不承诺大型学校或高并发性能。
- 提供环境变量、初始管理员、版本化迁移、自动验收、产物启动、Docker 配置及 CI；不能将配置已写好说成 Docker/公网已经实测上线。
